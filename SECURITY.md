# Security Policy

## Scope

Rogue-Lab-2 is a portfolio repository. It must not contain operational client data, credentials, endpoint artifacts, or instructions that enable harmful activity.

## Reporting a concern

Do not open a public issue or commit sensitive material. Report a suspected secret, sensitive artifact, unsafe instruction, or repository vulnerability to [stephen@roguemgmtgroup.com](mailto:stephen@roguemgmtgroup.com).

Include only the minimum information needed to locate the concern. Do not attach secrets, raw logs, images, or client identifiers. If a credential may have been exposed, revoke or rotate it through the owning system immediately; repository cleanup alone is not sufficient.

## Handling

The maintainer will acknowledge the report, assess scope, remove or quarantine sensitive content when appropriate, and document remediation without disclosing affected client details. No service-level response time is promised for this portfolio repository.

## Supported content

Only the default branch is maintained. Historical examples are illustrative and should not be treated as operational security guidance without review against the current engagement authorization and environment.
